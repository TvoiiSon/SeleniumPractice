1. Что оказалось проще/сложнее на Selenium по сравнению с Playwright?
- Playwright при создании браузера со scope session создает одно окно браузера на все тесты, но каждый тест получает чистый контекст браузера без кук и других (т.е. контекст в playwright со scope function), а Selenium в свое время создает также одно окно со scope session, но на каждый тест не приходит чистый контекст (т.е. Selenuim не чистит контекст перед новым тестом)
- Playwright при помощи get_by_role создает ленивый указатель, а у Selenium нет такой возможности, в случае чего будет возникать ошибка NoSuchElementException
